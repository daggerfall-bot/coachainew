Place app icons here before building:
  icon.ico  (Windows, 256x256 multi-res)
  icon.icns (macOS)
  icon.png  (Linux, 512x512)
  trayTemplate.png (16x16/32x32 tray icon; macOS uses Template naming)

Until you add these, the app builds and runs with Electron's default icon
and the embedded fallback tray dot in tray.js.
